# Code of Conduct

Nyx Player follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussions about the project. Harassment, insults and
personal attacks are not tolerated.

To report unacceptable behaviour, contact the maintainer at contact@nyxplayer.app.
